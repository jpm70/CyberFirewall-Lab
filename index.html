Laboratorio de Ciberseguridad: Retos Prácticos

        

        
      


      

        Pon a prueba tus conocimientos en topologías de red reales. Cada reto carga una configuración de firewall y un conjunto de pruebas automatizadas para validar la seguridad y la funcionalidad.
      


      
      

        
        
        

          

            

              RETO 1
              
Aislamiento de Servidores en DMZ

            

            Nivel: Intermedio
          

          

            Objetivo: La red interna LAN (192.168.1.0/24) debe poder consumir el servidor Web en la DMZ (172.16.0.10:80,443). Sin embargo, si el servidor web es comprometido, NO debe poder iniciar conexiones nuevas hacia la red LAN. El tráfico de respuesta legítimo debe funcionar mediante inspección stateful (ESTABLISHED).
          

          

            
            
          

          

        


        
        

          

            

              RETO 2
              
First Match Trap (El Impacto del Orden en Linux)

            

            Nivel: Fundamental
          

          

            Objetivo: Un administrador inexperto colocó una regla general de DROP ALL TCP por encima de la regla que permite ACCEPT Web 80. Demuestra cómo el tráfico legítimo queda atrapado y usa los botones ▲/▼ para solucionar el problema reordenando las reglas.
          

          

            
            
          

          

        


        
        

          

            

              RETO 3
              
Windows Firewall: Precedencia de Bloqueo Explícito

            

            Nivel: Avanzado
          

          

            Objetivo: A diferencia de Linux, Windows Defender Firewall aplica la regla de oro: Explicit Block overrides Allow. Demuestra que si existe una regla de bloqueo a una IP maliciosa, el paquete será descartado incluso si existe una regla permisiva previa en la lista.
